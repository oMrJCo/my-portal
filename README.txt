MY PORTAL
=========

Portal ส่วนตัวแบบง่ายสำหรับรวมลิงก์ Web App

ไฟล์:
- index.html
- style.css
- app.js

ความสามารถ:
- เพิ่มชื่อปุ่ม + Link
- แก้ไข
- ลบ
- Responsive มือถือ/คอม
- ข้อมูลที่เพิ่มเก็บใน localStorage ของ Browser

หมายเหตุสำคัญ:
V1 นี้ตั้งใจทำให้เบาที่สุด ข้อมูลที่เพิ่ม/แก้ไขจะอยู่เฉพาะ Browser/เครื่องนั้น
ถ้าต้องการให้ทุกเครื่องเห็นรายการเดียวกัน ต้องเพิ่มฐานข้อมูลกลางภายหลัง

การขึ้น GitHub Pages:
1. สร้าง Repository ใหม่ เช่น my-portal
2. อัปโหลด 3 ไฟล์ index.html, style.css, app.js ไปที่ root
3. Settings > Pages
4. Source: Deploy from a branch
5. Branch: main / root
6. Save
